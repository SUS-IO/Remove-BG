# Offline Background Remover (Windows)

GitHub builds the Windows app from `bg_remover.py`. The AI models are bundled inside, so the finished app works fully offline.

## Get the app
1. Open the **Actions** tab, then **Build Windows app**.
2. Open the latest green run and download **BGRemover-Windows** from the Artifacts section.
3. Unzip it, open the `BGRemover` folder and double-click `BGRemover.exe`.

## Use it
Choose the input folder and a different output folder, pick the output mode, and click Start.
Files already in the output folder are skipped, so you can stop and resume.
